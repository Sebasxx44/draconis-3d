# Dragón serpentino original v1 (archivo histórico)

Geometría procedural original creada para DRACONIS. No contiene recursos de terceros ni reproduce un modelo oficial de Caraxes. Es una interpretación provisional, sustituible por un GLB autorizado.

- Generador: `scripts/generate-dragon.mjs`.
- Esqueleto: cuello y cola con skinning, huesos de alas, cabeza y mandíbula.
- Animación integrada: `Flight`.
- Anclaje para fuego: `Mouth`.

La escena activa utiliza el rig Reborn, derivado de v2. Consulta `README-reborn.md`; el contrato reemplazable está en `src/components/experience/dragon-asset.ts` y su integración en `DragonWorldTA`.
